# Config Globals & File-Based Config

> Layer 3: File-based configuration and runtime globals

## CustomConfigUtils

**Location**: `include/utils/CustomConfigUtils.php`

Manages file-based configuration stored in PHP files.

### saveCustomConfigs($dotNotationArray)

Writes configuration to PHP file using dot notation.

```php
/**
 * Save custom configs to file
 * @param array $dotNotationArray Config in dot notation format
 * @return bool Success status
 */
public static function saveCustomConfigs(array $dotNotationArray): bool {
    $configFilePath = 'config_override.php';

    // Convert dot notation to nested array
    // 'callCenterConfig.enable' => true
    // becomes: ['callCenterConfig' => ['enable' => true]]

    $nestedArray = self::convertDotNotationToNested($dotNotationArray);

    // Generate PHP code
    $phpCode = "<?php\n";
    foreach ($nestedArray as $key => $value) {
        $phpCode .= "\$GLOBALS['{$key}'] = " . var_export($value, true) . ";\n";
    }

    // Write to file
    file_put_contents($configFilePath, $phpCode);

    return true;
}
```

**Example**:
```php
CustomConfigUtils::saveCustomConfigs([
    'callCenterConfig.enable' => true,
    'callCenterConfig.provider' => 'stringee',
    'callCenterConfig.api_url' => 'https://api.stringee.com',
    'smsConfig.enabled' => false
]);
```

**Generated File** (`config_override.php`):
```php
<?php
$GLOBALS['callCenterConfig'] = array(
    'enable' => true,
    'provider' => 'stringee',
    'api_url' => 'https://api.stringee.com'
);
$GLOBALS['smsConfig'] = array(
    'enabled' => false
);
```

### loadCustomConfigs()

Loads custom configs from file into `$GLOBALS` at application boot.

```php
/**
 * Load custom configs into $GLOBALS
 * Called during application initialization
 */
public static function loadCustomConfigs(): void {
    $configFilePath = 'config_override.php';

    if (file_exists($configFilePath)) {
        require_once $configFilePath;
    }
}
```

**Access Pattern**:
```php
// After boot, access via $GLOBALS
global $callCenterConfig;

if (!empty($callCenterConfig['enable'])) {
    $provider = $callCenterConfig['provider'];
    $apiUrl = $callCenterConfig['api_url'];
}
```

## Core Config Files

### config.inc.php

Core system configuration — **DO NOT EDIT** (generated by installer).

```php
// Database connection
$dbconfig['db_server'] = 'localhost';
$dbconfig['db_username'] = 'vtigeruser';
$dbconfig['db_password'] = 'password';
$dbconfig['db_name'] = 'vtigerdb';

// Application paths
$site_URL = 'https://crm.example.com';
$root_directory = '/var/www/html/vtigercrm/';

// Other system settings
$upload_maxsize = 3000000;
$application_unique_key = 'abc123xyz';
```

### config_override.php

Custom configuration overrides — **SAFE TO EDIT**.

```php
<?php
// Call center config
$GLOBALS['callCenterConfig'] = [
    'enable' => true,
    'provider' => 'stringee'
];

// SMS config
$GLOBALS['smsConfig'] = [
    'enabled' => true,
    'provider' => 'twilio'
];
```

## Global Access Patterns

### vglobal() Function

Safe global variable access.

```php
/**
 * Get global variable safely
 * @param string $varName Variable name
 * @return mixed Variable value or null if not set
 */
function vglobal(string $varName) {
    return $GLOBALS[$varName] ?? null;
}

// Usage
$siteUrl = vglobal('site_URL');
$rootDir = vglobal('root_directory');
```

### $GLOBALS Array

Direct access to runtime config.

```php
// Read config
global $callCenterConfig;
if (!empty($callCenterConfig['enable'])) {
    // Feature enabled
}

// Or use $GLOBALS directly
if (!empty($GLOBALS['callCenterConfig']['enable'])) {
    // Feature enabled
}
```

### global Keyword

Declare specific globals in function scope.

```php
function checkFeatureEnabled(): bool {
    global $callCenterConfig;

    return !empty($callCenterConfig['enable']);
}
```

## Common Config Access Patterns

### Feature Toggle Check

```php
class PBXManager_Config_Helper {
    public static function isCallCenterEnabled(): bool {
        global $callCenterConfig;

        if (empty($callCenterConfig['enable'])) {
            return false;
        }

        return true;
    }
}
```

### Get Config Value with Default

```php
global $callCenterConfig;
$provider = $callCenterConfig['provider'] ?? 'default';
$apiUrl = $callCenterConfig['api_url'] ?? 'https://api.default.com';
```

### Conditional Config Loading

```php
global $callCenterConfig;

if (!empty($callCenterConfig['enable'])) {
    $dbConfig = Settings_Vtiger_Config_Model::loadConfig('callcenter_config', true);
    // Use DB config for detailed settings
}
```

## When to Use Each Config Type

| Config Type | Use When |
|---|---|
| **File Config** (`$GLOBALS`) | Static server settings, feature flags, rarely changed values |
| **DB System Config** | Dynamic module settings, API keys, thresholds, frequently changed |
| **User Preferences** | User-specific UI settings, per-user behavior, notifications |

**Example Workflow**:
1. **File Config**: Enable/disable call center feature globally
2. **DB System Config**: Store provider API credentials, sync settings
3. **User Preferences**: Each user's auto-answer preference, ringtone choice
