# VTiger Models & Entity

> Samples use a **fictional** module `CPDemo` (`vtiger_cpdemo` + `vtiger_cpdemocf`). Real field names come from `vtiger_field` / the module's `BlocksAndFieldsRegister.php`.

## Entity Definition (CRMEntity)

### Purpose
Define database structure, fields, relationships for a module.

### Location
`modules/{Module}/{Module}.php` — generated by Quick Repair from the module template (see `create-module.md`); edit only when the defaults need overriding.

### Class Structure
```php
include_once 'modules/Vtiger/CRMEntity.php';

class CPDemo extends Vtiger_CRMEntity {

	var $table_name = 'vtiger_cpdemo';
	var $table_index = 'cpdemoid';

	// Mandatory table for supporting custom fields
	var $customFieldTable = array('vtiger_cpdemocf', 'cpdemoid');

	// MUST include vtiger_crmentity for proper CRM behavior
	var $tab_name = array('vtiger_crmentity', 'vtiger_cpdemo', 'vtiger_cpdemocf');

	var $tab_name_index = array(
		'vtiger_crmentity' => 'crmid',
		'vtiger_cpdemo' => 'cpdemoid',
		'vtiger_cpdemocf' => 'cpdemoid',
	);

	// ListView columns: label => fieldname
	var $list_fields_name = array(
		'Name' => 'name',
		'Assigned To' => 'assigned_user_id',
	);

	var $default_order_by = 'name';
	var $default_sort_order = 'ASC';
}
```

### Critical Rule
**Entity tab_name MUST include `vtiger_crmentity`** for:
- Ownership tracking (`assigned_user_id` field → `vtiger_crmentity.smownerid`)
- Soft delete support (`deleted` column)
- Creation/modification timestamps
- CRM-wide features (sharing, workflows, etc.)

## Record Model (Instance Operations)

### Purpose
CRUD operations on individual records.

### Location
`modules/{Module}/models/Record.php`

### Get Existing Record
```php
// By ID — throws Exception when the record is missing or deleted
$record = Vtiger_Record_Model::getInstanceById($recordId, $moduleName);

// By conditions
$record = Vtiger_Record_Model::getInstanceByConditions($moduleName, ['field_name' => $value]);
```

### Create New Record
```php
$record = Vtiger_Record_Model::getCleanInstance($moduleName);
$record->set('field_name', $value);
$record->set('assigned_user_id', $userId);
$record->save();

$recordId = $record->getId();
```

### Update Existing Record
```php
// Method 1: set + save
$record = Vtiger_Record_Model::getInstanceById($recordId, $moduleName);
$record->set('mode', 'edit'); // required for updates
$record->set('field_name', $newValue);
$record->save();

// Method 2: updateData (batch update)
$record->updateData([
	'field_name' => $newValue,
	'another_field' => $anotherValue,
])->save();
```

### Delete Record
```php
$record->delete(); // Soft delete (sets deleted = 1)
```

### Get Field Values
```php
$value = $record->get('field_name');
$id = $record->getId();
$moduleName = $record->getModuleName();
```

### Custom Record Model
```php
class CPDemo_Record_Model extends Vtiger_Record_Model {

	// Progress in percent from current vs target value
	public function getProgress(): float {
		$target = (float) $this->get('target_value');

		if ($target == 0) return 0;

		return ((float) $this->get('current_value') / $target) * 100;
	}

	public function isCompleted(): bool {
		return $this->getProgress() >= 100;
	}

	// Keep the parent signature exactly when overriding
	public function save() {
		$this->set('progress', $this->getProgress());

		return parent::save();
	}
}
```

## Module Model (Module-Level Operations)

### Purpose
Module-wide operations, metadata, search.

### Location
`modules/{Module}/models/Module.php`

### Get Module Instance
```php
$moduleModel = Vtiger_Module_Model::getInstance($moduleName);
```

### Module Information
```php
$moduleId = $moduleModel->getId();
$moduleName = $moduleModel->getName();
$isEntityModule = $moduleModel->isEntityModule();
```

### Field Information
```php
// Get all fields
$fields = $moduleModel->getFields();

// Get specific field
$field = $moduleModel->getField('field_name');
$fieldType = $field->getFieldDataType();
$uitype = $field->get('uitype');
```

### Custom Module Model
```php
class CPDemo_Module_Model extends Vtiger_Module_Model {

	// Module-wide query delegated to the helpers
	public function getActiveItems(): array {
		return CPDemo_Logic_Helper::getActiveItems();
	}
}
```

## ListView Model

### Purpose
Handle list view queries, filtering, pagination, buttons.

### Location
`modules/{Module}/models/ListView.php`

### Custom ListView
```php
class CPDemo_ListView_Model extends Vtiger_ListView_Model {

	// Add a list view button next to the parent's basic links
	public function getBasicLinks() {
		$links = parent::getBasicLinks();

		$links[] = array(
			'linktype' => 'LISTVIEWBASIC',
			'linklabel' => 'LBL_SYNC_DATA',
			'linkurl' => 'javascript:CPDemo_List_Js.syncData()',
			'linkicon' => 'fa-refresh',
		);

		return $links;
	}
}
```
